# Documentation Steward Skill

Use this skill **proactively at the end of every task or experiment** so documentation stays synchronized with the codebase without requiring user reminders.

## Golden Rule
**Never create `README.md` inside `docs/`.** Always update the exact canonical file matching the type of information produced:

## Exact Routing Table

1. **Task Progress, Issue/PR Links, Milestone Status**
   ➔ **`docs/status/PROJECT_STATUS.md`**
   - Update `Last Updated`, `Active Branch`, `Quality Gate Status`, and the Executive Task Board row (`TASK-XX`, GitHub Issue `#N`, PR `#M`, status emoji).

2. **Session Resumption, Reboot Handoff, Next Immediate Steps**
   ➔ **`docs/status/HANDOFF_RESUME.md`**
   - Record current audit/CV/LB metrics, non-negotiable guardrails (e.g., VRAM limits, CV split keys), and exact commands for the next session.

3. **Hardware Limits, Env/ABI Traps, Leakage Invariants, Submission Ledger**
   ➔ **`docs/notes/MASTER_MEMORY_COMPILATION.md`**
   - Document Kaggle GPU/timeout ceilings, dependency quirks, offline workarounds, and every submission/experiment entry (`Version`, `Local CV`, `Public LB`, `Submission Ref`).

4. **Dataset Schema, Class Balance, Group Keys, Domain Shift**
   ➔ **`docs/research/DATASET_EDA.md`**
   - Update train/test shapes, target distributions, grouping columns (`GroupKFold`/`StratifiedGroupKFold`), and data anomalies.

5. **CV Scores, Ablation Tables, Latency/VRAM Profiling**
   ➔ **`docs/research/BENCHMARK_ANALYSIS.md`**
   - Log baseline vs candidate configurations, exact metric deltas, runtime/memory measurements, and keep/discard decisions.

6. **Clean Architecture Layers, Module Additions, ADRs**
   ➔ **`docs/architecture/SYSTEM_DESIGN.md`**
   - Update the `src/` directory diagram and append a numbered ADR (`Context`, `Decision`, `Consequences`).

7. **CLI Commands, Env Vars, Release Notes**
   - Update root **`README.md`** and **`.env.example`** when adding `Makefile` targets, CLI flags, or environment variables.
   - Update **`CHANGELOG.md`** on milestone or release cuts.
   - Never manually edit **`summary.md`** (auto-generated by `make audit`).
